## Алгоритм запуска приложения

### Шаг 1. Клонирование репозитория
`git clone <URL>`
### Шаг 2. Создание и активация виртуального окружения
`python -m venv .venv`

`source .venv/bin/activate`
### Шаг 3. Установка зависимостей
Убедитесь, что в корне проекта есть файл requirements.txt, затем выполните:

`pip install -r requirements.txt`

### Шаг 4. Применение миграций
`python manage.py migrate`
Это создаст все необходимые таблицы в базе данных (SQLite по умолчанию).

### Шаг 5. Создание суперпользователя
`python manage.py createsuperuser`
Следуйте подсказкам для ввода логина, email и пароля.
Суперпользователь нужен для входа в Django Admin (/admin/).

### Шаг 6. Запуск сервера разработки
`python manage.py runserver`
Сервер запустится по адресу: http://127.0.0.1:8000.
